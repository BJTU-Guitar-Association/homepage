前言

本部分内容来自北交吉协2014年至今的公众号文章及部分访谈记录。受限于资料来源， 我们难以仅凭现有材料完整还原所有曾在北交活动过的乐队及其相关信息。因此，部分早期乐队乃至近年新组建的乐队，其介绍难免存在一定偏差或资料缺失。 若读者发现文中任何错误或不足之处，敬请联系网站维护人员（邮箱见通讯录📇）或吉协内部相关人员。我们衷心感谢读者的批评与指正。

路恩&鲸鱼旧线（2025-至今）

内心的希望创造出美的旋律，现实的荒原生长出疲惫的愤怒，伴随着脆弱性的嘶吼， 勇敢地展示出一种不迎合而又难以捉摸的力量感，暴露出脆弱，沮丧和缺陷同时又歌唱着向上和接受对音乐边界及市场的探索，以及多年来对摇滚乐的潜心热爱， 最终确立了他独有的唱腔和演奏气质：通过音乐、态度、声音，以及澄澈的情绪，发觉渴望被听到的声音：垃圾乐(grunge)朋克乐(punk)的不羁与颓废， 抑或是细腻的情感和悦耳的流行乐(pop)旋律。不哗众取宠，只是喧闹地、旋律简约而极为原创地诉说着。

活动流程

为保证每学期社团能有两次集中活动，一般来说上半期百团前办一个路演，百团后可根据情况办一个专场；下半期四月办路演，五月办专场。其中，专场规模>路演规模。

乐队

负责人需在活动举办前至少两周时统计好参演乐队及曲目，收集宣传需要用到的各个乐队的介绍，可以将每个队的队长拉进演出工作群，在工作群中，负责人需：

曲目

当前国际形势较为动荡，北交又为首都高校，文化艺术活动难免受到波及。因此，负责人需确认节目单中有无任何敏感内容。若有，需及时与该乐队协商，并对节目单进行调整，附上歌词，交与相关审核部门。

灯光
室外

吉协自己有变色灯，为了演出效果更好，会去找位于射箭馆的鲁大兴老师借补光灯搭配使用。

室内

小剧场有较为完善的灯光系统，如果准备充分可以达到很不错的灯光效果：

  • 在统计演出曲目时收集每首歌的灯光要求（颜色/速度，如果更细致可以在歌词上标注）；
  • 将排好顺序的曲目做成歌单，并按顺序打印所有灯光要求；
  • 提前3-4天带着社团自留一份的申请表和打印出的灯光要求，去小剧场中控室找灯光师傅协商，把做好的歌单和灯光要求都发给当天值班的灯光师傅。灯光师傅同时也负责小剧场的开门事宜；

只有小剧场需要彩排。负责人需在统计节目时也将彩排顺序排出来，彩排的目的是踩点、试音和方便师傅编写灯光。所以在申请小剧场时需要申请至少一整天的时间。演出当天的白天全部用于彩排。

音箱使用说明
简述
输入

吉他音箱的输入主要有两种方式：

  • input：位于前面板，代表使用箱头的前级与后级；
  • return：位于箱头背后，代表仅使用箱头的后级。

大多数情况下，建议仅使用箱头的后级。此时需要在效果器上关闭箱体模拟，以获得更稳定的音色，同时确保前级模拟（pre-amp）和箱头模拟（amp）已经开启。

切换音色

若音色调试不符合预期，需要使用前级时，可按以下方式切换：

  • 关闭效果器的箱头模拟；
  • 仅使用效果器上的非箱头类效果接入音箱的 input；
  • 箱头优先使用 clean 箱头；
  • 失真源优先使用效果器上的单块失真。

这样更便于快速对比不同音色，并减少因箱头模拟带来的色彩偏差。

单次使用时长

单次使用时长不应超过 4 小时。每次使用结束后，应将音箱关闭并进行冷却，避免电子管因高温影响正常工作状态，或因过热导致音箱失效。

箱头与箱体的连接方法可参考 zhuanlan.zhihu.com。对于黑星音箱，通常只需将箱头的 mono 与箱体连接的 mono 对接即可，阻抗一般为 16Ω。

电气安全

排练室是一个会接入大量电气设备的场所，请确保所有设备都是完好的、没有电路故障或是电路元件损坏的。建议经常对自己的设备进行检查，电吉他电贝斯需要保证接地良好，合成器等数字设备则要注意电源适配器的电压和正负性是否匹配。 同时使用时需要符合安全规范，保持手部干燥，避免在排练时触碰带电部分，特别是分体式电子管音箱连接箱头箱体的连接线。使用完设备后应及时关闭电源，保持排练室的安全环境。 在冬天或初春，天气干燥，静电频发。建议乐手在接电之前先脱去易起电的衣物，然后触摸一些大型或接地的金属件，以释放静电。如果自己的体质是易起静电的， 千万不要在触碰金属弦的同时开门、摸设备的导电部分或其他金属物体，以防吉他到音箱的接地不良，从而导致漏电伤害到自身。正确的做法是扭掉吉他的音量，放下吉他，寻找接地金属件释放静电，再进行其他操作。

一定一定要遵守音箱的正确使用规范：所有吉他音箱，都应该先确认power与standby开关处于关闭状态。接下来，连接好所有需要接入音色链的设备，接好所有供电插头。 再确认音色链全部接口和顺序均准确无误、音色链上没有裸露的接头，所有接头都牢固地接入接口。最后，打开power开关，确认红灯亮起并等待三分钟及以上，等暖机后再打开standby开关至需要的档位进行演奏。 贝斯箱流程一致，也同样需要暖机，不过只需要确认一个开关就好了。

在standby模式下，音箱的电子管会保持工作状态，但是音箱会停止输出切断输入，以避免电子管过热。此时可以拔线。但standby模式不可保持超过半个小时，否则可能损伤电子管。

音色链故障的排除与归因

如果在进行了音箱的开关机操作后，发现演奏时没声音或事音色异常，则我们需要进行音色链的排除与归因。

首先我们要确认是否有线路连接错误或接触不良。接着我们要确认乐器音量旋钮是否开的太小、效果器输出音量或增益是否过小、音箱的前后级增益和总音量输出大小是否合适。注意每次插拔线都要将 如果通过重新连接和参数调整仍不能解决问题，则需要进行控制变量的对比试验，确认是线材、吉他、效果器还是音箱的问题。如果是吉他、效果器或线材的问题，请自行解决； 如果是音箱的问题，请立即关闭音箱并断电，同时联系排练室负责人。

音箱的前后级增益和总音量输出千万不能开太大！推荐前后级增益均不超过70%，总音量输出大小不超过50%。

禁忌事项
  1. 不要在箱头正在工作时拔插输入接口，尤其是 return 与 input；如果必须拔插，请先确保箱头处于 standby 模式。热插拔时的"噗"声可能会导致功放或喇叭损坏。
  2. 不要使用过细的线材连接箱头与箱体。即使接口尺寸相同，也应使用专门用于音箱连接的粗线，避免不出声、线材过热或声音变闷。
  3. 贝斯音箱需正确连接。主动贝斯通常接主动输入口，被动电路则应接高阻抗输入口；主动电路接高阻抗口时，可能导致破音或烧毁放大电路。

*若需要进一步确认具体连接方式，建议先确认音箱的输入类型与设备阻抗，再进行实际接线。

*若设备在排练时出现了损坏，请由乐队负责人及时报告排练室负责人，并协商后续流程。

*想对于各类设备的技术细节有更进一步的了解，建议咨询认识的各领域大佬。

*推荐电吉他手都进行一些基本的电子电路知识学习，了解音响、效果器、电吉他的工作原理。可以参考这位up的视频进行一些基本的了解点击了解

预约表

吉协的社团性质决定了我们需要供乐队成员练习和排练的空间，也就是活动室。我们的活动室已由嘉园地下室A28-40转变为学活505，从专属活动室转变为和学校其它社团的共用活动室。

吉协坚持为每一个热爱音乐的成员提供便利，奈何时间和空间都是有限的，所以排练室施行每周一开放小程序统一预约，供各队负责人查看和预约合适且空闲的时间。

小程序使用：每位成员都需要在小程序上注册账号，之后注册队伍，由队长拉人完成队伍的注册。在管理员审核通过后，即可在预约界面查看并预约排练室空闲时间。我们强烈建议每支队伍将已经排好的歌曲同步在小程序上，方便演出的规划。

在此，我们也提供之前一直使用的预约表表格，作为历史的见证与备份。

为避免人数过多过杂，我们采取的措施是每个队仅出一人进入排练室预约群，且只有经过排练室负责人审核的队负责人能在小程序预约，尽可能确保大家都能公平有序进行预约和排练，达到最大利用率。

摊位

摊位表演和路演专场性质不同，没有那么正式，重点在于制造出动静吸引人来。可仿照办路演专场的形式，提前给能参演的乐队排一个大致的顺序，一般从下午两点开始至五点，不需要严丝合缝，不需要阵容完整。
